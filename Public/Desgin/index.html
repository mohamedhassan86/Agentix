Spec Kit workflow · GitHub-native

Ship production software with agents that live inside your repository.

SpecOps is a multi-tenant delivery platform for spec-driven engineering. Issues labelled sdlc start a run: an agent per phase specifies, clarifies, plans, decomposes and implements — committing real specs/NNN-feature/*.md artifacts and opening a draft pull request for your team to review.

  • Organizations, members & roles. Owner, admin, member and viewer scopes with project-level isolation.
  • Encrypted by default. LLM keys, GitHub tokens and webhook secrets sealed with AES-256-GCM, org-scoped and never exposed to agents or logs.
  • Agents per phase. Choose the org key (Anthropic, OpenAI, Azure OpenAI, Gemini, OpenRouter), model, temperature, rules and Spec Kit skills.
  • Judge scoring. Read-only tools run before hooks; the Judge scores Completeness, Correctness, Specificity and Measurability after hooks and feeds the producing agent.
  • Metered to the token. Every call is attributed to org, project, run, phase and agent with budget hard stops.
  • Keyless Mock agent + Simulated repository. Exercise the entire pipeline before you spend a cent.

Security posture

Secrets are encrypted at rest with AES-256-GCM using per-organization data keys wrapped by KMS. Agents receive scoped, short-lived proxy credentials — never the raw key. Every decryption is written to the audit log with actor, project, run and phase context.
