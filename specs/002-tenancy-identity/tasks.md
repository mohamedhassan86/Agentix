# Tasks: Tenancy & Identity (002-tenancy-identity)

**Input**: Design documents from `/specs/002-tenancy-identity/` — `spec.md`, `plan.md`, `research.md`, `data-model.md`, `contracts/openapi.yaml`, `contracts/events.md`, `quickstart.md`

**Prerequisites**: `specs/001-solution-foundation` delivered (46/46 tasks, gates green). Foundation supplies Next.js 16 host, worker, Prisma 7 baseline with `@prisma/adapter-pg`, outbox, composition root, Problem Details, telemetry, design tokens, test harness. Do not re-scaffold foundation.

**Tests**: Required — unit (domain/application/UI), integration (persistence/api/tenancy), contract (OpenAPI/events), e2e (Playwright identity golden path), security (redaction/isolation), performance (10k rows). Within each story: write tests first, verify they fail for intended reason, then implement. Coverage floors: domain ≥90% lines, application handlers ≥80%, plus mandatory named suites for permission matrix, concurrent Owner invariant, tenant isolation per operation, token lifecycle, throttle.

**Organization**: 8 phases (each ≤10 tasks). Phases 3-5 are P1 vertical slices (register, create org, invite), Phases 6-7 are P2 (roles/invariant, switch/isolation/platform). Every phase ends with `npm run lint && npm test && npm run build && npm run license:check && npm run architecture:check && npm run openapi:check && npm run test:policy` or subset — red gate blocks next phase.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel after preceding unmarked dependency in same phase (different files, no race).
- **[Story]**: Maps to US1–US5 from `spec.md`.
- **Paths**: Concrete repository paths. No `src/domain` importing outside Domain; no `src/application` importing Infrastructure/App/Worker/React/Next/Prisma; `src/app` routes thin (<150 lines, one parse + one dispatch).
- **Security**: No password/hash/token/session in DTOs, logs, events, metrics, traces, ProblemDetails, snapshots, OpenAPI; raw token only in issued message URL, stored as SHA-256 digest, encrypted outbox payload AES-256-GCM until terminal dispatch then purged.
